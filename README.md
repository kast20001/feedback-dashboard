# Дашборд обратной связи ФТМИ

Прототип дашборда для анализа анкет обратной связи (ОС) студентов и преподавателей по дисциплинам. Проект ППМ-3 2026.

> Все данные в репозитории — **демо**: дисциплины, группы, преподаватели, оценки и комментарии придуманы для примера.

## Что внутри

Три вкладки и общие фильтры по программе, дисциплине и преподавателю.

| Вкладка | Что показывает |
|---|---|
| **01 Общее** | Охват (записались → сдали → оставили ОС, доля ответов), индекс качества дисциплин, заполняемость и достоверность по группам, автоматические сигналы |
| **02 Студенты** | Оценка курса, полезность для профессии, удовлетворённость, новизна, ожидания, сложность, что мешало учиться, атмосфера и командная работа, комментарии |
| **03 Преподаватели** | 7 критериев оценки преподавателя, профиль группы глазами преподавателя, зеркальные вопросы (атмосфера, сложность), диагностика «где проблема», отметки студентов |

## Как запустить

Сборка не нужна. Откройте `index.html` в браузере или включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Как обновить данные

1. Замените файлы в папке `data/` (формат — массив объектов, поля как в демо-файлах).
2. Пересоберите `assets/data.js`:
   ```bash
   python tools/build_data.py
   ```

### Поля `data/groups.json` (одна строка = группа × дисциплина)

| Поле | Значение |
|---|---|
| `course`, `teacher`, `group`, `program` | Дисциплина, преподаватель, группа, образовательная программа |
| `enrolled`, `passed`, `responses` | Записались, сдали, оставили ОС |
| `overall`, `satisfaction`, `usefulness`, `novelty` | Средние 1–5 из анкеты студентов |
| `expect_yes`, `expect_partial`, `expect_no`, `not_my_choice` | Доли ответов про ожидания |
| `difficulty_st`, `atmosphere_st`, `team_issue`, `urgent_st` | Сложность и атмосфера (1–5), доля проблем в командах, число срочных сообщений |
| `t_atmosphere` … `t_structure` | 7 критериев оценки преподавателя, 1–5 |
| `g_engagement`, `g_homework`, `g_level`, `g_discipline`, `g_atmosphere`, `g_difficulty` | Оценка группы преподавателем, 1–5 |
| `incidents`, `urgent_t`, `flag_*` | Инциденты, срочные запросы, количество отметок студентов |

`data/barriers.json` — сколько ответивших в группе отметили каждый барьер; `data/comments.json` — выборочные комментарии.

## Правила

- Результаты группы скрываются при 5 ответах и меньше.
- Достоверность: от 50% ответов — надёжно, 30–49% и от 10 ответов — ограниченно, иначе — низкая.
- Сигналы и формулы метрик описаны в ТЗ проекта и в блоке «Как считаются метрики» внизу дашборда.

## Структура

```
index.html              страница дашборда
assets/dash-runtime.js  источники данных, расчёты, фильтры, отрисовка
assets/data.js          данные для страницы (собирается из data/)
data/*.json             исходные данные
tools/build_data.py     сборка assets/data.js
```
